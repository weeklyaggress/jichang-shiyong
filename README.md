## 「5 天 5G」这个额度，能测什么

很多人觉得 5G 太少。其实要看你测什么。

**能测的：**

- 峰值速度（跑一次测速就知道上限）
- 晚高峰表现（20:00-23:00 各测一次，对比白天）
- 流媒体解锁（Netflix / Disney+ / YouTube 4K 能不能开）
- 延迟与丢包（游戏、视频会议能不能用）
- 客户端兼容性（小火箭、Clash、Stash 能不能正常导入）

**测不出的：**

- 长期稳定性（这本来就要靠时间，任何试用都测不出）
- 大流量场景（5G 用完就没了，别指望拿它下片子）
- 长期成本（要看你实际每月用多少）

**结论：5 天 5G 的作用是「排雷」，不是「当免费机场用」。** 拿它把上面五项跑一遍，够用了。

## 试用期必做的四项测试

按顺序做，每项都有明确的判断标准。

### ① 晚高峰测速（最重要）

白天测速没有意义——所有机场白天都很快。真正拉开差距的是 **20:00-23:00**。

做法：晚上 21 点左右，用 Speedtest 连你常用的节点跑三次，记录下载速度。

判断标准：

| 结果 | 说明 |
|---|---|
| 三次都在峰值的 70% 以上 | 线路质量好，没有明显超售 |
| 掉到 30%-50% | 普通中转线路的正常水平 |
| 掉到 10% 以下或频繁断流 | 严重超售，别买 |

### ② 流媒体解锁

打开 Netflix，搜一部只在特定区上架的剧；或者开 YouTube 看 4K 是否缓冲。

不需要测全部平台，测你**真正会用**的那一两个就够。很多人测了一堆解锁，结果自己只看 B 站。

### ③ 延迟与丢包

命令行 `ping` 你的节点地址，看平均延迟和丢包率。

- 延迟 150ms 以内、丢包 0%：视频会议、游戏都够用
- 延迟 300ms 以上或丢包 >3%：只适合看网页

### ④ 多设备同时连接

手机 + 电脑 + 平板同时连，看是否限速或踢设备。

**这条最容易忽略，但很关键**：有些机场宣传「不限设备」，实际同时在线上限是 2 台。你家里三台设备就露馅了。

## 怎么判断是不是「真中高端」

「中高端」是营销词，没人会自称低端。要看四个能验证的东西。

**① 线路类型**

| 类型 | 特点 | 成本 |
|---|---|---|
| IPLC / IEPL 专线 | 不过公网，晚高峰稳定 | 最高 |
| 中转（BGP） | 国内入口 + 海外出口，性价比高 | 中 |
| 直连 | 便宜，晚高峰容易崩 | 低 |

真中高端通常至少是**中转起步，主力节点用专线**。宣传页不写线路类型的，大概率是直连。

**② 晚高峰掉速幅度**

见上面第①项测试。这条比任何宣传语都真实。

**③ 工单响应速度**

提一个技术问题（比如「Clash 导入后无法连接」），看多久回复、回复是否有实质内容。

**回复模板话术的，说明没有技术支持能力。**

**④ 节点数量 ≠ 质量**

「全球 200+ 节点」这种宣传没有意义。20 个维护良好的节点，远胜 200 个互相抢占带宽的节点。
